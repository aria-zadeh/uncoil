# Adversarial edge cases, batch 1. FINE_TUNING.md section 3.1.
#
# These teach the model what to do when the input is not a tidy assignment:
# one-word titles, titles with no verb, tasks that are already a single atomic
# action, very long descriptions, unusual subjects, non-English fragments, and
# empty details.
#
# The completions here are deliberately GENERIC. When the input names nothing,
# a step may not invent anything, so the right answer is a plain, physical
# sequence that would be useful for any assignment. Teaching the model to
# hallucinate specifics from a one-word prompt is exactly the failure the
# hallucination check exists to catch.
